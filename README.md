# PLP Data Analytics with Python Assignment 2: Rainfall Advisory

## Project Summary
This project cleans raw monthly rainfall records across five Kenyan counties (Nairobi, Nakuru, Kisumu, Mombasa, and Machakos), imputes missing values in the Machakos dataset, and uses NumPy array operations to identify annual totals, wettest months, dry-spell counts, and optimal two-month planting windows.

## How to Run the Notebook
1. Install the required dependency (`numpy`) from `requirements.txt` using `pip install -r requirements.txt`.
2. Open `rainfall_analysis.ipynb` in Google Colab or Jupyter Notebook.
3. Select **Runtime > Run all** to execute all cells from top to bottom and generate `rainfall_summary.csv`.

## Planting Advisory
* Farmers in Nairobi, Nakuru, Kisumu, and Mombasa should prepare land in March and plant during the April–May long rains, which bring the highest consecutive two-month rainfall.
* Farmers in Machakos should prioritize planting during the November–December short rains and select drought-tolerant crops to withstand its six dry months.
